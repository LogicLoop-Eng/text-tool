# Text Tool

A Ruby-based text analysis and processing tool that generates interactive HTML reports with statistical insights, NLP-style analysis, and text utilities.

## ✨ Features

* 🔤 Text processing and normalization
* 📊 Word and character statistics
* 😊 Basic sentiment analysis
* 🔑 Keyword extraction
* 📝 Extractive text summarization
* 🔍 Search and text highlighting
* ♻️ Redundancy and repeated-pattern detection
* 📖 Reading-time estimation
* 🧠 Vocabulary diversity and text complexity analysis
* 🌐 Basic language detection
* 🧹 Noise and unnecessary-content detection
* 📄 Export to PDF, Word, and JSON
* 🌓 Interactive dark/light mode
* 🌍 Support for Persian and Finglish text

## 📊 Interactive HTML Report

The tool generates an interactive HTML report that presents the analysis results in an easy-to-read format.

The report includes statistics, detected patterns, keywords, sentiment information, and other text insights.

## 🚀 Getting Started

### Requirements

* Ruby 3.0 or later

### Run

Clone the repository:

```bash
git clone https://github.com/LogicLoop-Eng/text-tool.git
cd text-tool
```

Run the program:

```bash
ruby text_tool.rb
```

The program generates an interactive HTML report based on the analyzed text.

## 🌍 Persian & Finglish Support

The project was designed with Persian and Finglish text in mind and includes several text-processing features that can be useful for Persian-language content.

## ⚠️ Limitations

This project mainly uses rule-based and heuristic methods rather than advanced machine-learning or deep-learning NLP models.

Therefore, the analysis should be considered experimental and educational rather than a professional NLP system.

## 💡 Why I Built This

I built this project as a practical experiment in text processing and natural language analysis using Ruby.

At the time, internet access in Iran was heavily restricted, which made installing libraries, packages, and development tools difficult. Instead of relying on external dependencies, I explored what could be built with the tools and languages that were already available.

This project is the result of that experiment: building a relatively feature-rich text analysis tool with Ruby and standard web technologies.
